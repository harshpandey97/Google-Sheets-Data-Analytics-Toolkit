# Sheets Mini-Projects

Applied projects that combine multiple modules — good candidates for a portfolio addition.

## Suggested Projects

1. **Personal/Household Budget Tracker**
   - Data validation dropdowns for category, SUMIF for category totals, pivot table for monthly summary, chart for spend by category.

2. **Job Application Tracker**
   - Ties directly into current job search — columns for company, role, status, applied date; conditional formatting by status; DATEDIF for days-since-applied; pivot summary of applications by status/week.

3. **Sales/Revenue Dashboard (mock data)**
   - Pivot table + pivot chart + slicer, combo chart (revenue vs growth %), XLOOKUP for product lookups — a Sheets-native companion to the existing Power BI Superstore Sales Dashboard project.

4. **Automated Weekly Report (Apps Script)**
   - Script that pulls new rows, formats them, and emails a summary — demonstrates automation skills beyond formulas.

Add a `project-name/` folder here for each one once started, with the sheet link and a short README.
