# Keyboard Shortcuts — Quick Reference

**Ctrl + Arrow** — cursor jumps to the last non-empty cell in that direction, or the next non-empty cell if you're on the edge of a blank gap. Fastest way to navigate large datasets without scrolling. (`Ctrl + Shift + Arrow` does the same but **selects** the range while moving — most-used combo for selecting a whole column/row of data.)

**Ctrl + Shift + L** — toggles AutoFilter (dropdown arrows) on the header row of your selected range. Same shortcut works in both Excel and Google Sheets. Cursor must be inside your data range (or a header row selected) before pressing it.

**F2** — puts the active cell into edit mode, cursor placed at the end of the existing content — no need to double-click. Press `Home`/`End` to jump within the cell, `Esc` to cancel edit without saving, `Enter` to confirm.

---

**Quick table:**

| Shortcut | Action |
|---|---|
| Ctrl + Arrow | Jump to edge of data region |
| Ctrl + Shift + Arrow | Jump **and select** to edge of data region |
| Ctrl + Shift + L | Toggle filter dropdowns |
| F2 | Edit active cell |
| Ctrl + ; | Insert today's date |
| Ctrl + Shift + $ | Apply currency format |
| Alt + = | AutoSum |
| Ctrl + 1 | Open Format Cells |
