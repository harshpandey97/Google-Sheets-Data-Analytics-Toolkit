A structured, hands-on journey through Google Sheets — from core formulas to dashboard-level analytics — built as a public learning log and portfolio proof for **Data Analyst / BI Analyst** roles.

Every concept here is backed by a **notes file** (theory + syntax) and a **practice file** (applied exercises), so this repo doubles as both a personal reference and evidence of hands-on skill.

## 🧭 Learning Phases

| Phase | Focus Area | Notes | Practice |
|-------|-----------|-------|----------|

## 🚀 Key Skills Demonstrated

- Formula-based problem solving (VLOOKUP → XLOOKUP → INDEX-MATCH progression)
- Dynamic reporting using `QUERY` and `ARRAYFORMULA`
- Data cleaning & validation for real-world messy datasets
- Pivot table–driven summarization and chart building
- Dashboard design for business reporting
- (Optional/if applicable) Apps Script automation for repetitive tasks

## 📈 Why This Repo

Most fresher portfolios stop at "I know Excel/Sheets." This repo shows **progression** — from basic formulas to dashboard-level thinking — mirroring how a real Data/BI Analyst would use Google Sheets for quick reporting and stakeholder-facing dashboards before scaling to Power BI/SQL.
