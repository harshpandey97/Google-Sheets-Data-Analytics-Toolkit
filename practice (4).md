
# ⌨️ Keyboard Shortcuts — Notes & Practice Guide

---

## Key Concepts & Cheat Sheet

Keyboard shortcuts significantly speed up data entry, navigation, and formatting without needing to touch the mouse.

| Action / Exercise | Windows / Linux Shortcut | Mac Shortcut | Description |
| --- | --- | --- | --- |
| **Jump to Edge** | `Ctrl` + `Arrow Key` | `Cmd` + `Arrow Key` | Jumps to the first or last cell with data in that direction. |
| **Select Range to Edge** | `Ctrl` + `Shift` + `Arrow Key` | `Cmd` + `Shift` + `Arrow Key` | Selects all cells from the current position to the end of the data block. |
| **Toggle Filter On/Off** | `Ctrl` + `Shift` + `L` | `Cmd` + `Shift` + `L` | Instantly creates or removes filters on the top header row. |
| **Edit Active Cell** | `F2` | `Enter` (or `Fn` + `F2`) | Opens the active cell for editing directly, placing the cursor at the end. |
| **Fill Down** | `Ctrl` + `D` | `Cmd` + `D` | Copies the value/formula from the cell directly above. |
| **Toggle Absolute ($)** | `F4` | `Fn` + `F4` | Toggles between `A1`, `$A$1`, `A$1`, and `$A1` while editing a formula. |

## 🛠️ Practice Exercises

Set up your **`Keyboard Shortcuts`** tab with a sample data table (e.g., 20+ rows of items and prices) and perform these 3 core exercises using **only your keyboard**:

1. **Exercise 1: Navigate a Large Dataset (Ctrl + Arrow Keys):** Master fast navigation without scrolling.
1. Click on cell **`A1`**.
2. Press **`Ctrl + Down Arrow`** $\rightarrow$ Instantly jumps to the very last row of your dataset.
3. Press **`Ctrl + Right Arrow`** $\rightarrow$ Moves to the last column on the right.
4. Press **`Ctrl + Up Arrow`** $\rightarrow$ Returns back up to row 1.
5. **Selection Combo:** Press **`Ctrl + Shift + Down Arrow`** from `A1` to highlight the entire column of data instantly.


2. **Exercise 2: Toggle Filters (Ctrl + Shift + L):** Apply filters instantly without the menu.
1. Click anywhere inside your data table (or highlight the header row `A1:C1`).
2. Press **`Ctrl + Shift + L`** $\rightarrow$ Notice the filter drop-down icons appear on your headers.
3. Press **`Ctrl + Shift + L`** again $\rightarrow$ Toggles the filter off.


3. **Exercise 3: Edit Cells via Keyboard (F2):** Speed up formula and text editing.
1. Use your arrow keys to navigate to any cell with text or a formula.
2. Press **`F2`** instead of double-clicking with your mouse.
3. Notice how your cursor enters the cell automatically.
4. Make your text edits or update your formula, then press **`Enter`**.
