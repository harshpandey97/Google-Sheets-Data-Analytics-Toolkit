## 📁 Structure

Each module folder contains:
- `notes.md` — concept summary + formula syntax
- `practice.md` — exercises to do inside an actual Google Sheet (link your sheet here once created)

`projects/` holds applied mini-projects that combine multiple modules (e.g. a budget tracker using formulas + charts + data validation).

## 🎯 Goal

Build enough Sheets fluency to support Excel/Power BI work in data analyst roles, and add 1–2 portfolio-ready Sheets projects (e.g. a dashboard or automated tracker) linked from the main portfolio.
