# Formulas & Functions

## Key Concepts

- =SUM(), =AVERAGE() — aggregate basics
- =IF(), =AND(), =OR() — conditional logic
- =VLOOKUP() / =HLOOKUP() / =XLOOKUP() — lookups (XLOOKUP is the modern replacement)
- =INDEX() / =MATCH() — flexible two-way lookups
- =COUNT(), =COUNTA(), =COUNTIF() — counting with conditions
